# AI pipeline: провайдеры, ограничения, эксперименты

> Статус: исследование от 2026-10-14. Ни один провайдер ещё **не испытан** на
> реальных материалах. Всё ниже — по документации и страницам провайдеров;
> цены и лимиты нужно перепроверить перед подключением.

## 3. Подход A против подхода B

**A. Готовый hosted video-editing API** (Kling O3 Edit / Wan Replace / Aleph):
один вызов, провайдер сам держит GPU. Быстро встроить, качество задаёт
провайдер, оплата за секунду выхода, жёсткие лимиты длительности (3–15 с).

**B. Многоэтапный pipeline** (детекция и трекинг людей, замена по сегментам,
inpainting окружения, сборка): больше контроля и потенциально длиннее
ролики, но это месяцы ML-работы и собственные GPU.

**Решение:** начинаем с A. B вводится по частям только там, где A упирается в
ограничения, и только на бэкенде:

- склейка аудио (ffmpeg) — сразу, это дёшево и надёжно;
- нарезка длинного ролика на сегменты ≤10–15 с и склейка результата — после
  проверки качества на коротких роликах;
- распознавание персонажей для экрана Character Mapping — позже.

## 4. Стратегия «без бюджета» (по запросу автора)

Полностью бесплатного и стабильного production-варианта для такой генерации
сегодня нет: модели тяжёлые (14B+), а бесплатные GPU-квоты маленькие.
Поэтому:

1. **Этапы 1–4 — бесплатно.** Весь UI, бэкенд, очередь и экспорт строятся
   на `MockProvider`, который ничего не генерирует и явно маркирует
   результат как тестовый.
2. **Первые реальные эксперименты — бесплатно:** `HuggingFaceSpaceProvider`
   вызывает публичный Space с Wan 2.2 Animate через `gradio_client` с
   бесплатным HF-токеном. Только для разработки: одна замена персонажа,
   короткие ролики, очереди и квоты, Space может пропасть.
3. **Альтернатива без денег:** ComfyUI + квантованный Wan Animate на
   бесплатном GPU (Kaggle/Colab). Медленно, вручную, не проверено —
   подходит для оценки качества, не для приложения.
4. **Когда появится бюджет:** `FalProvider`. Самый дешёвый вариант — Wan
   Replace 480p: ролик 10 с ≈ $0.40 (оценка по цене со страницы, не проверено
   счётом). Kling O3 Edit 10 с ≈ $2.52 — для нескольких персонажей и смены
   окружения.

Подключение любого платного провайдера — только после согласования с автором.

## 5. Целевой pipeline на бэкенде

1. Приём файлов, проверка MIME, размера и длительности.
2. `ffprobe`: кодек, fps, длительность, поворот, наличие аудио.
3. Нормализация (ffmpeg): H.264 mp4, допустимые разрешение и fps,
   извлечение аудиодорожки.
4. Подготовка референсов: проверка размеров фото (≥300×300 для Kling).
5. Сборка промпта: текст пользователя + `@Element`/`@Image` ссылки.
6. `GenerationProvider.submit(...)` → id задачи у провайдера.
7. Опрос статуса (позже — webhook).
8. Скачивание результата в наше хранилище.
9. Если провайдер не сохранил звук и пользователь выбрал «оставить звук» —
   remux оригинального аудио (`ffmpeg -map`), сверка длительности.
10. Выдача клиенту по подписанной/непубличной ссылке, удаление исходников по
    сроку хранения.

## 6. Чего мы не обещаем пользователю

Пока это не подтверждено испытаниями, UI и описание в сторах **не
утверждают**, что модель сохраняет мимику, точный монтаж, синхронизацию губ
или переходы. Звук сохраняется только путём remux исходной дорожки, при
условии, что длительность результата совпадает с исходником.
